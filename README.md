Managingenterprisecomputernetworkshasbecomeacomplex,criticalandtime-consuming
task. Technical teams must continuously monitor a large volume of data from heteroge-
neous sources (network devices, servers, application logs) while reacting quickly to inci-
dents and security threats.
This academic project, carried out at ENSA Kénitra (Ibn Tofail University), proposes
an artificial intelligence solution able to automatically detect abnormal network behavior
and to prioritize alerts, so the administrator can focus on the most critical incidents first.

Through interviews with systems and network professionals (Section 3), we found that
supervision relies on tools such as Zabbix or pfSense, but several limitations remain in
the detection, analysis and prioritization of incidents. The needs gathered in the field can
